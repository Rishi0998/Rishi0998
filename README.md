## Experience & Projects

### Protocol X — Zero-Trust AI Firewall &nbsp; `2024 – Present`

> Security perimeter for large language models and GenAI systems.

Architected and built a multi-stage detection pipeline to defend proprietary AI models against prompt injections, jailbreaks, and data exfiltration. The system combines lexical filtering, behavioural anomaly scoring, and semantic intent analysis in a zero-trust authorization model between the user session and the LLM backend.

`Python` &nbsp;`NLP` &nbsp;`AI Safety` &nbsp;`Zero Trust Architecture` &nbsp;`Semantic Analysis`

---

### AI Forensic Time Machine — Incident Reconstruction Engine &nbsp; `2024`

> AI-powered log forensics and attack timeline reconstruction for blue-team operators.

Built an ingestion and analysis pipeline that normalizes raw server, firewall, and OS event logs, applies AI-based attack pattern detection, reconstructs a visual intrusion timeline from correlated events, and auto-generates an executive triage report with prioritized remediation guidance.

`Python` &nbsp;`Cyber Forensics` &nbsp;`Log Analysis` &nbsp;`Incident Response` &nbsp;`AI`

---

### Nextron — Intelligent IoT Vehicle &nbsp; `2023`

> Autonomous hardware platform with five integrated control modalities.

Designed and built a smart vehicle supporting hand gesture detection, voice recognition, Bluetooth SPP command streaming, ultrasonic obstacle avoidance, and manual override. Wrote low-latency embedded firmware in C/C++ for real-time sensor fusion across all five input systems.

`Embedded C/C++` &nbsp;`IoT` &nbsp;`Arduino` &nbsp;`Sensor Fusion` &nbsp;`Bluetooth`

---

### Digital Media Ecosystem &nbsp; `2022 – Present`

> Founder and operator of a 3M+ subscriber content network.

Scaled a digital media operation from zero to over three million subscribers using data-driven content strategy, algorithmic behaviour modelling, and cross-platform audience development. Work spans CTR optimization, retention analysis, A/B testing, and community operations.

`Growth Analytics` &nbsp;`Content Strategy` &nbsp;`SEO` &nbsp;`Audience Psychology`
