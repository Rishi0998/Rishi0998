# 🚀 Supercharge Your GitHub Profile — 3-Minute Setup Guide

Everything has been generated for you in this workspace! Here is how to launch it:

---

### Step 1: Create Your Special GitHub Profile Repository
1. Log into your GitHub account.
2. Click **New Repository** (`https://github.com/new`).
3. Set the **Repository name** to your exact **GitHub Username** (for example, if your username is `rishi-sharma`, the repo name must be `rishi-sharma`).
4. Make sure it is marked as **Public** and check **"Add a README file"**.
5. Click **Create repository**.

---

### Step 2: Replace Your Username in `README.md`
Open the generated `README.md` file in this directory and replace all occurrences of `rishikesh-cyber` with your **actual GitHub username**:
- Press `Ctrl + H` (Find & Replace)
- **Find:** `rishikesh-cyber`
- **Replace with:** `<your_actual_github_username>`
- Update your social links (LinkedIn URL, YouTube Channel link) at the bottom!

---

### Step 3: Enable the Contribution Snake Animation (Automated)
Your repository includes `.github/workflows/snake.yml`. To make it run:
1. Push the `.github/` folder to your profile repository.
2. Go to your repo on GitHub: **Settings** ➔ **Actions** ➔ **General**.
3. Scroll down to **Workflow permissions**.
4. Select **"Read and write permissions"** and click **Save**.
5. Go to the **Actions** tab in your repository ➔ Click on **"Generate Snake Contribution Grid"** on the left ➔ Click **"Run workflow"**.
6. The snake eating your commits will now animate and automatically refresh every 12 hours!

---
